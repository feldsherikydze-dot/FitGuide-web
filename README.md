# FitGuide Web

[![Deploy to GitHub Pages](https://github.com/feldsherikydze-dot/FitGuide-web/actions/workflows/deploy.yml/badge.svg)](https://github.com/feldsherikydze-dot/FitGuide-web/actions/workflows/deploy.yml)

🌐 **Живая версия:** https://feldsherikydze-dot.github.io/FitGuide-web/

Веб-версия (PWA) приложения **FitGuide** — карманный тренер для силовых тренировок.
Работает в любом браузере на любой платформе: Android, iOS, десктоп.

Можно установить как приложение: в браузере → «Установить приложение» / «Добавить на главный экран».
После установки ярлык открывает FitGuide в отдельном окне без адресной строки — как обычное приложение.

---

## Возможности

| Раздел | Что внутри |
|--------|-----------|
| **Тренер** | Готовность к тренировке, план дня, автопрогрессия весов, разгрузочные недели |
| **Программы** | Генератор: фулбоди / сплит / круговая, периодизация (линейная, волновая), цели, уровень, место тренировок |
| **Тренировка** | Журнал подходов, вес / повторы / подходы, таймер отдыха, оценка «как зашло» |
| **Прогресс** | Графики e1RM, личные рекорды, объёмы по периодам |
| **Упражнения** | 200+ упражнений с техникой, биомеханикой, типичными ошибками и советами |
| **Таймер** | Обратный отсчёт, секундомер, пресеты, звук и вибрация |
| **Музыка** | Локальные треки, радиостанции, плейер с историей |
| **Профиль** | Замеры тела, BMR / TDEE, макронутриенты, доступное оборудование |
| **Настройки** | Тема, экспорт / импорт данных (JSON), установка PWA |

## Технологии

- React 18 + TypeScript
- Vite 5
- Tailwind CSS 4
- Zustand (состояние + persist в localStorage)
- React Router
- Service Worker (офлайн-работа)

## Данные

Все данные хранятся **только на устройстве** (localStorage). Ничего не отправляется на сервер.
Экспорт / импорт — в разделе «Настройки».

## Запуск локально

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run preview    # предпросмотр собранной версии
```

## Деплой

Статическая сборка из `dist/` — кладётся в корень репозитория или в папку `/web`.
GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / `/web`**.
